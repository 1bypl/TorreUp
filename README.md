# TorreUp
Lokalna, prywatna przeglądarka torrentów z nowoczesnym interfejsem w stylu serwisu torrentowego, działający wyłącznie na Twoim komputerze.  TorreUp nie jest klientem torrentów i nie pobiera plików samodzielnie. To wyszukiwarka, która znajduje metadane i przekazuje linki magnet do wybranego klienta (Transmission, qBittorrent, Deluge itd.).
